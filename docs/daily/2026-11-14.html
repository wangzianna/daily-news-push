今日重点

  • 券商数智化转向中后台：中证协启动财务数智化应用调研。这意味着券商AI落地已经从财富管理、投研等前台业务扩展到财务、合规、风控、运营环节；截至2026年7月末，已有32家券商完成算法与模型备案、备案项目超50个（其中10余家头部券商完成多模型备案）。由此看，2026年被称为“金融智能体元年”，竞争重点将从“能不能用”转向“能否被核算、被审计、被规模化验证”。（中证报/36氪，官方发布；仅有摘要，未获取到全文）
  • 腾讯用元宝搜索争夺“默认入口”：元宝搜索网页版 so.qq.com 面向普通用户开放，并可在QQ浏览器设为默认搜索引擎。此前，该能力已在元宝、WorkBuddy、ima 等50多个业务中使用，日均调用数亿次。判断：AI搜索已从能力输出进入C端入口争夺阶段，但在7.82亿搜索用户（CNNIC，截至2025年12月）的存量市场中，让用户更换默认入口的成本远高于技术门槛。（36氪，官方发布）
  • 国产开源生信大模型挑战海外闭源模型：无界前沿开源 Fx-Bio-1031（开放完整权重、支持本地部署），在 BioMysteryBench 困难子集取得 70.59% Pass@5，高于 GPT-6-Astra（47.06%）与 Claude Opus-5（52.94%）；BiomniBench Pass@3 达 89.50%。这些成绩为厂商自述的 benchmark 结果；真正的竞争变量是“数据不出域”能否成为国内科研与药企的采购依据。（量子位，官方发布、媒体报道）

行业动态

  • 金价与油价同步走弱，交易主线从地缘政治风险切回宏观：黄金期价收于3886.30美元/盎司，周跌超4.6%，纽约与布伦特油价均跌2.5%。通胀黏性预期与美联储偏紧预期推高美元与美债收益率，压制贵金属；IEA预计2026年Q4全球石油供应转向过剩，叠加美伊外交谈判预期，使原油的地缘溢价回吐。（央视财经/36氪，仅有摘要）
  • 个体化肿瘤疫苗首次三期临床阳性，mRNA赛道重新受到关注：Moderna 的个体化新抗原肿瘤疫苗（intismeran autogene 联合帕博利珠单抗，用于完全切除的黑色素瘤术后辅助治疗）取得首个三期临床阳性结果。这是mRNA技术在预防性疫苗之外的关键验证点，但商业化仍取决于个体化制备成本与产能。（财新，证据类型：媒体报道转述三期临床结果；仅有摘要）
  • 美国药价管制在红州取得突破：北达科他州两党合作对胰岛素自付费用设置上限，加入全美逐步扩大的州级药价保护行动。该迹象表明，药价议题已经形成跨党派的政治共识空间，制药企业的定价策略将持续承受州级压力。（KFF Health News，证据类型：媒体报道）

AI / 科技

  • ChatGPT Wallet 让 agent 获得“受控支付”能力：在 ChatGPT Work、Codex、dots 中，agent 可在用户批准下完成购买，并沿用现有银行卡保护。这是 agent 商业化闭环的关键一环——价值不仅在于支付本身，更在于把“授权—确认—追责”设计成标准流程。（OpenAI 官方发布）
  • 垂直科学模型成为美国主要AI公司竞争的核心领域：OpenAI（GPT-Rosalind 系列）、Google（Gemini for Science）、Anthropic（Claude Science）在半年内完成“垂直模型+评测基准+科研工作台”的全栈布局。Fx-Bio-1031 的开源路径提供了另一种可能：以可本地部署来换取合规与数据安全优势，但代价是放弃闭源服务的规模化变现。（量子位，官方发布）
  • 更省数据的训练方法让气候模拟器更实用：MIT 团队的新训练技术仅需常规一小部分数据，就能提升气候 emulator 的性能与适应性，把这类秒级模拟工具的生产时间大幅压缩，使它更快用于电网韧性、公共卫生与农业规划等决策场景。（MIT News，模型能力更新）

产品设计相关

  • “research-in-the-loop”：研究必须跟上 AI 开发节奏：NN/g 指出，AI agent 写代码让迭代成本接近“数字摄影”，团队倾向于先发布再看结果；但软件发布不像废照片那样可以丢弃，它会触达真实用户。研究方法应从“上线前验证”转为“内嵌在发布流程中”——为每个版本预先定义必须衡量什么、能帮团队发现什么。（NN/g，全文）
  • 入口型产品的竞争核心在于切换成本，而不是功能多少：元宝搜索把已有能力（服务50多个业务、日均数亿次调用）从 API 转为 C 端网页产品，但产品负责人李锐章明确表示，让用户更换默认入口需要面对已经变化的市场。对产品团队的含义是：AI 搜索的胜负取决于用户习惯与分发渠道，而不是回答质量单点对比。（36氪）
  • 规则设计必须回应真实使用场景，否则难以执行：电单车非法改装屡禁不止，新一轮治理需要回应骑手实际用车需求。这是典型的“合规目标与用户真实场景错位”问题，对涉及履约、配送类产品的合规与硬件设计同样适用。（财新，仅有摘要）

值得关注的信号

  • agent 的权限边界正成为新的产品与合规设计重点：支付授权之后，身份核验、额度控制、误操作追责会像当年的“隐私授权弹窗”一样，演变为通用设计模式。（OpenAI）
  • “数据不出域+本地可部署”可能成为国内 B 端 AI 采购的关键条件：开源垂域模型以合规优势切入，闭源海外模型即使 benchmark 领先也未必能进入课题组与药企的真实工作流。（量子位）
  • 政策执行层的细节缺口会直接造成用户流失：美国 Medicaid 工作要求虽豁免原住民，但联邦未提供统一识别机制，各州核查方式不一；此前 2023 年资格复核（unwinding）期间，估计约85万原住民在2024年5月前失去覆盖，多为程序性原因。任何涉及资格判定的产品化流程，都应把“豁免能否被系统自动识别”当作设计重点，而不是事后补丁。（KFF Health News，证据类型：媒体报道）
