📅 2026-09-08 科技与行业观察

今日重点

最高法为涉 AI 纠纷划定司法规则 最高法发布《关于依法审理涉人工智能纠纷案件的意见》，明确 AI 换脸拟声、网络开盒、大数据杀熟等场景的侵权责任认定；利用 AI 处理特定自然人或死者人格要素，不得违法或违背公序良俗。判断：深度合成类产品将面对更可执行的司法合规底线，涉及肖像、声音等要素的功能需在产品设计阶段就嵌入授权与场景边界审查。（财新，官方发布）

GPT-6 系列双线浮出水面 Astra 发布后，GPT-6 Sol 被曝内测：输出规模接近 Astra，但单次测试速度约为其 6 倍，推测是面向规模化 Agent 调用的高吞吐模型（网友爆料，未经官方确认）。同日 OpenAI 公开内部数据，研究院人均每天有超 3 个 Agent 工作日并行运转，中位数研究员日均使用 Agent 推理资源超 600 美元。判断：模型家族化分工 + 研发流程 Agent 化是 OpenAI 的两条明确主线。（量子位，官方数据与社区爆料混合）

世界模型成早期融资新热点 世界模型初创「WorldMind」成立不到一个月即完成数千万元天使轮融资，元生资本投资，资金用于团队建设与基础模型训练。创始人任云帆 26 岁任同济大学博导、曾为大疆算法预研骨干，CTO 张奇来自脑视觉解码与类脑智能方向。判断：世界模型赛道正争抢“具身智能 + 脑科学”交叉背景的人才组合。（36氪，仅有摘要）

行业动态

国产首发碳化硅超级结 MOSFET 瑶芯微电子与中科院院士郝跃团队发布全球首款碳化硅超级结功率器件。海外厂商目前占全球约 80% 碳化硅器件份额，并将超级结定义为 2027 年后的下一代方向；此次中国先发若能量产落地，将直接影响新能源汽车、数据中心 800V 供电、光伏储能等下游的器件供给格局。（36氪，仅有摘要）

物理 AI 企业深度智控连获三轮融资 B+ 轮数亿元融资落地，宁德时代领投，沙特阿美旗下 Aramco Ventures 等跟投，两个月内累计完成三轮。公司核心是把 AI 与物理机理结合，实现工业及算力基础设施的自主决策与闭环控制，产品已延伸至液冷智控、算电协同。判断：AI 算力扩张对电力与散热的压力，正在让“物理 AI”成为能源巨头和产业资本的共同押注方向。（量子位，官方发布）

Snowflake 转机重估软件业 Snowflake 财报带动软件板块情绪修复。此前 IGV 指数因“AI 吞噬软件”担忧大幅回调，但市场开始意识到：AI 调用越频繁，企业数据平台的存储与计算调用量越高，数据基础设施正成为 AI 时代的“收费站”。判断：有存量数据壁垒的平台型软件不会被大模型替代，反而会因 AI 使用量增长获得新定价权。（财新，分析观点）

AI / 科技

MiniCPM5-2B 开源，端侧 Agent 雏形出现 面壁智能联合 OpenBMB 发布新一代端侧模型 MiniCPM5-2B，仅 2B 参数即支持工具调用、深度搜索与代码生成，初步具备端侧通用 Agent 能力。判断：端侧模型正从“轻量问答”走向“自主执行”，隐私敏感、离线运行和低响应延迟场景将最先受益。（36氪，官方发布，仅有摘要）

办公 Agent 用户行为出现“重度化”拐点 基于 LobsterAI 数据的报告显示：前 20% 用户消耗了 87.4% 算力，前 5% 独占 53.5% token；付费用户 token 消耗、任务量与月活跃天数分别是免费用户的 6.2 倍、5.2 倍和 3.0 倍。判断：办公 Agent 的付费模型正被验证——“用得越重越愿意付费”，而非付费带动用量。（量子位，数据报告）

Playco 用 GPT-6 Astra 减少 50% 手动修复 游戏公司 Playco 在自建 IDE「Playbot」中接入 GPT-6 Astra，让模型直接操作 Unity 与 Godot，完成场景编辑、运行测试与缺陷修复；从同一灰盒基础生成了三个主题游戏原型，手动修复减少 50%。判断：模型对空间与 UI 响应的理解提升，正把 AI 从“写代码的工具”升级为“能在真实引擎里自我验证的开发者”。（OpenAI News，官方发布）

产品设计相关

AI 已能一次性生成可玩原型 GPT-6 Sol 在 zero-shot 条件下，用 15 分钟、6 万 token 生成了一个像素风沙盒世界：包含城镇、河流、城堡、缩略地图及昼夜切换、地名编辑等控制面板，接近模拟经营游戏雏形。含义：概念设计瓶颈不再是“做不出来”，而是如何筛选方向——设计评审的输入物将从静态稿变为可交互、可实测的系统。（量子位，社区爆料）

AI 辅助设计进入“闭环自修正”阶段 Playco 案例的关键不在于生成效果，而是 GPT-6 Astra 能在引擎里运行测试、发现 bug 并修正自己生成的内容。对产品团队的启示：AI 设计工具的评估指标应从“生成效果”转向“自修正率”——AI 能在多大程度上在真实环境中发现并解决自己的问题。（OpenAI News，官方发布）

Agent 产品的界面正在变成“日程” 办公 Agent 数据显示，12.2% 的模型调用非实时发起，定时任务单条指令平均带动 64 次模型调用（人工任务仅 10.6 次）；微信、钉钉等聊天窗口已成为 17.9% 的任务入口。设计含义：“无人值守”应成为 Agent 产品的一等使用场景，任务状态推送、异常干预和完成审阅比对话流畅性更重要。（量子位，数据报告）
